功能一览

为 dsh 打造的完整桌面体验

不止是套壳：从启动自愈、双源更新到文件改动追踪，围绕 dsh 的实际使用打磨了一整套桌面化能力。

免装 Node

内置独立 Node 运行时与 npm CLI，目标机器无需安装 Node.js，双击即跑。

内置 dsh CLI

完整打包 @deepseek-ai/dsh 及全部插件，离线可用，升级只动内置配套插件。

一键启动

双击启动 dsh web，优先复用上次端口（占用自动换新），稳定 origin 记住界面偏好。

无边框窗口 + 托盘

自绘玻璃标题栏、Win11 圆角、系统托盘；关闭默认隐藏到托盘，退出即清理进程树。

便携版

数据跟随 exe 所在目录，拷到 U 盘即用；首次解压后缓存到临时目录，后续秒开。

共享 CLI 配置

默认沿用 DSH_HOME（通常是 ~/.dsh），已有会话与 API Key 直接生效，与命令行 dsh 完全一致。

双重自动更新

官方 dsh agent 更新 + 客户端封装自更新（GitHub/Gitee 双源、分片自动合并、原地重启），均经同意。

插件升级兼容

更新只升级内置配套插件，不会覆盖你自行添加的第三方插件与 cordis.patch.yml 条目。

余额小部件

对话底部统计栏显示「本轮 ¥X · 余额 ¥Y」，点击跳转充值；可一键关闭，免被中转用户打扰。

文件改动追踪 + 还原

详情面板「文件」标签查看本会话全部改动（行级 diff），逐文件或全部一键还原。

会话完成通知

agent 任务跑完时弹 Windows 系统通知，点击回到窗口，长任务不用盯着看。

dsh-vision 识图

配置 OpenAI 兼容 VLM 即可用 view_image 工具 OCR / 看图 / 读图表，默认智谱免费 glm-4.6v-flash。

还有更多

渲染进程崩溃自愈、插件市场（npm / github:）、WSL 托管模式、会话导航滑轨、隐藏对话输出……

工作原理

三层结构，本机回环加载

Electron 壳负责生命周期与窗口，内置 node.exe 跑 dsh web，原生窗口只加载本机回环地址的 Web UI。

01 / 壳

Electron 主进程

单实例锁、无边框窗口、托盘与生命周期，spawn 内置 node.exe 跑 dsh web。

02 / 引擎

内置 node.exe + dsh

路径解析：用户目录 overlay > 内置包；输出 dsh web: http://127.0.0.1:<port>。

03 / 界面

原生窗口加载 Web UI

轮询 HTTP 200 后加载到原生窗口，仅本机回环访问，稳定 origin 持久记住偏好。
