# DSH Desktop v0.5.4 — Tauri 2

> 本版本聚焦**多 agent 白屏根治** + **WSL 后端五问题** + **第三方思考强度**三大方向，累计修复 20+ 项用户反馈的 BUG。

## ⚠️ 重点：多 agent 客户端卡顿/白屏 —— 根治

这是 v0.5.4 的硬门禁项。根因是内核 UI 的会话事件流**无上限累积**，多子代理跑一会儿就吃光 WebView2 渲染进程内存导致白屏。

- **治本**：会话事件有界保留（2000 条封顶，按轮次对齐裁剪）+ 会话 `dispose()` 真正释放内存（切/删会话不再常驻）
- **自愈**：白屏后三级恢复梯自动救活（eval reload → 原生 reload → 浏览器进程级重载），不再永久白屏
- **熔断**：连重载都救不活时自动升级到内核重启，不再「40 秒一次」无限闪屏循环

实测：8 个并发子代理 × 4000 事件压测，内存斜率趋平（此前线性堆积）。

## 🔄 升级说明

1. 完全退出当前 DSH Desktop（托盘右键 → 退出）
2. 下载对应平台安装包并运行
3. 安装器自动检测旧版并装回原目录（**数据不丢失**）
4. 首次启动自动同步全部插件与设置

> macOS 首次打开如提示「已损坏」，右键 app → 打开，或 `xattr -cr "/Applications/DSH Desktop.app"`（未公证签名所致，非安装包损坏）。
